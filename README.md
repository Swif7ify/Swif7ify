## 👨‍💻 About Me

I'm an **Information Technology student at Gordon College** in Olongapo City, Philippines, with a strong interest in building complete products — from the interface people interact with to the systems and hardware running underneath.

My primary areas are **Python** and **full-stack development**, but I also enjoy exploring embedded systems, custom electronics, PCB design, game development, AR/VR, and interface design.
